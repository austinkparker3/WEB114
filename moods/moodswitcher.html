Project 7--DOM and JS

Javascript Questions

1. Why is textConnect safer than innerHTML?

Answer: TextConnect treats everything as plain text, which does not execute scripts or HTML, whereas HTML treats input as HTML Code. This parses and renders the script, allowing for the execution of hacked or malicious scripts.

2. How are HTML elements connected to JavaScript variables using DOM selection?

Answer: HTML elements get connected to JavaScript variables via the DOM - Document Object Model - which allows JavaScript to locate elements in the webpage and store references to them within variables.

3. What would happen to the text box with id="text" if I added this line to the Code above it:

            text.textContent = "Hello!"

Answer: The word "Hello" would completely overwrite the word "text" within the element.
